#### 03 · [TokensCache](https://github.com/kais-aljammal/tokenscache) — Semantic Cache & Optimization Layer
> High-performance caching middleware and prompt-optimization engine built for multi-provider AI agents. Eliminates repetitive token expenditure through exact SHA-256 hash caching, cosine vector similarity matching, real-dollar budget limits, and MCP tooling. Validated with 92/92 automated Vitest tests, demonstrating a **35.5% token reduction** across coding-agent scenarios with zero output fidelity degradation.

- **Stack:** `TypeScript` · `Model Context Protocol (MCP)` · `Vector Embeddings` · `Vitest` · `Node.js`
- **Endpoints:** [Repository ↗](https://github.com/kais-aljammal/tokenscache) · [Engineering Breakdown ↗](https://kais.live/blog/building-tokenscache.html)
